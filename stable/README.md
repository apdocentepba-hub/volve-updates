# Canal estable

Por seguridad todavía no hay ninguna actualización anunciada. No crear `manifest.json` ni `manifest.sig` con versiones simuladas o ejecutables no validados.

Cuando exista una versión REAL del panel comprobada en Windows, publicar el par firmado `manifest.json` y `manifest.sig` correspondiente. El agente instalado solo admite actualizaciones del panel; no actualiza motor DNS, catálogo ni el propio agente.
