# VOLVÉ — web independiente de Lovable
Migración de la web informativa desde el proyecto Lovable `49ccf194-5633-4d7d-a58d-1606ef7e07ff` (29/10/2026).
Conserva React, Tailwind, presentación, contenidos y seis páginas originales. Suma una página integrada de asistencia bonaerense con 45 recursos.
## Instalación y compilación
```
cd site
npm install
npm run dev
npm run build
```
## Render Static Site
Repositorio: https://github.com/apdocentepba-hub/volve-updates, rama main, build command `cd site && npm install --no-audit --no-fund && npm run build`, publish directory `site/dist`, auto-deploy activado.
Sin base de datos ni API de pago. Hasta verificar la publicación no cambiar enlaces originales ni perfiles sociales.
